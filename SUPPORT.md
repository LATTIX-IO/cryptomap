# Support

## Bugs and feature requests

Use GitHub Issues for reproducible defects, feature proposals, documentation gaps, and implementation questions that are appropriate for public discussion.

## Security issues

Do not open a public issue for a suspected vulnerability. Use GitHub Private Vulnerability Reporting or the security contact documented in SECURITY.md.

## Commercial support

These repositories are open-source projects. Public issue trackers do not create a commercial support obligation or response-time commitment.
